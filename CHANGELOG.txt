IWDEE Tweaks and Fixes - Changelog
==================================

v0.4-dev (unreleased)
---------------------
- Added Rogue Rebalancing shared-HLA compatibility for the vanilla Shadowdancer: Scribe Scrolls -> Crippling Strike, Evasion -> Danger Sense, Greater Evasion -> RR Evasion, and Alchemy -> RR Alchemy. The active vanilla Shadowdancer HLA route is discovered dynamically. ZS Shadowdancer Overhaul's separate `ZS_SHADOWDANCER` / `LUZSSD` HLA design is explicitly preserved, making the integration compatible with both the stock kit and the overhaul; this mirrors the vanilla-kit mapping of ZS's optional RR compatibility component #5001 without requiring that component.
- Synced all v0.3b fixes into the v0.4 development branch: component #0 now includes the validated Bardic Wonders vanilla Bard/Paladin HLA routing repair in both the Standard and Rogue Rebalancing HLA variants, and component #5 mirrors Bardic Wonders' optional overhead Bard Song visual onto all six classic IWDEE songs when `C0BSNGEF.SPL` is present.
- Added Rogue Rebalancing's Bard-specific Alchemy and full Scribe Scrolls implementations to the RR HLA variant, replacing only the vanilla Bard `SPCL918`/`SPCL919` HLA entries while preserving Bardic Wonders and other custom Bard HLAs.
- Added structural compatibility with Epic Thieving's Epic Trap Setting: preserve Set Death Trap and the scaling Exploding Trap damage/radius tiers, add RR-compatible successful-save avoidance and large/heavy-creature exclusions to Exploding Trap's secondary knockback/knockdown effects, and still replace Time Trap with Acid Trap.
- Added mutually exclusive component #0 choices for standard Thief HLAs or Rogue Rebalancing Thief HLA Revisions.
- RR Thief HLA integration discovers active Thief HLA tables dynamically, preserves mod-added HLA entries, handles the vanilla Shadowdancer through a dedicated RR compatibility layer while preserving ZS Shadowdancer Overhaul's custom route, preserves A7 Sharpshooter's Missile Trap, and uses installed potion resources for RR Alchemy.
- Component #1 recognizes RR Alchemy and Crippling Strike so the Fighter/Mage/Thief result matches the RR-recommended Triple-Class -> RR order semantics.
- Synced the v0.4 development baseline with the stable v0.3a component #4 fixes, including Skills and Abilities #131 Enhanced Skald Song selector compatibility and the Curran Strongheart / Tymora portrait icon corrections.
- Completed in-game validation of the previously integrated RR HLA paths: Acid Trap, Epic-compatible Exploding Trap, Alchemy, Crippling Strike, Danger Sense, Evasion, Insightful Strike, BG2-style RR icons, Fighter/Mage/Thief tables, A7 Sharpshooter preservation, and ZS Shadowdancer preservation. The newly added vanilla-Shadowdancer RR compatibility layer still requires focused in-game verification.
- Added mutually exclusive Giant Vermin installation choices: an IWDEE-balanced progression (recommended) summoning 2/3/2/2/1 beetles across the five caster-level tiers, and the IWD2-faithful one-beetle progression.
- Made component #6 recover safely from the noncanonical SPPR418 layout produced by the earlier v0.4-dev test build by normalizing the retained casting-effect index after deleting old ability headers.
- Fixed Giant Vermin summoning an immediate Fire Beetle at casting time zero and a second beetle on spell completion by retaining casting feature blocks at the start of SPPR418's feature table and placing level-scaled summon effects after them.
- Fixed component #6 installation on IWDEE by using the native `BEETLEG.CRE` source for the Fire/Base Beetle tiers and applying IWDEE's Fire Beetle animation (`0xE210`) to the former; removed invalid `BEETFIRE.CRE` and `BEETLE.CRE` requirements.
- Split component #6's native creature checks so a skipped installation now identifies the exact missing CRE resource.
- Added optional mutually exclusive components #6/#7: Rework Giant Insect as IWD2-Style Giant Vermin.
- Replaced the random 2-3 creature Giant Insect result with a configurable level-scaled progression: Fire at caster levels 7-8, Beetle at 9-10, Bombardier at 11-12, Boring at 13-14, and Rhinoceros at 15+.
- Reconstructed the IWD2 summoned-creature combat profiles as native IWDEE V1.0 creatures without redistributing IWD2 game files.
- Added dedicated natural weapons with the IWD2 damage dice while preserving species-specific IWDEE attack effects and behavior.
- Implemented the IWD2 duration of 10 rounds per caster level with exact level-aware spell headers through level 50.
- Preserved the installation's current Giant Insect icon, targeting, range, casting time, projectile, casting effects, and top-level spell metadata.
- Dedicated summons award no XP, carry no gold, drop no loot, leave no corpse, use no death variables or dialogue, and count toward the normal summoning cap.
- Updated the Giant Insect spell description to document the new progression.
- Passed WeiDU 24900 structural installation and binary-resource validation; in-game validation remains pending.
- Development work is isolated from the stable v0.3b `main` baseline.

v0.3b
-----
- Added a Bardic Wonders HLA compatibility repair for IWDEE installations where Bardic Wonders Bard HLA rows are routed to the vanilla Paladin table: component #0 removes only the misplaced `C0BWHL*` rows from the vanilla Paladin table and restores the intended vanilla Bard HLA set without altering Bard kits.
- Extended Bardic Wonders' optional Bard Song overhead visual to the six classic IWDEE selectable songs when `C0BSNGEF.SPL` is present.
- Both fixes were validated in game: vanilla Paladin no longer receives Bard HLAs, vanilla Bard receives the correct Bardic Wonders HLAs, kitted Bards remain unchanged, and all six classic songs display the overhead visual.

v0.3a
-----
- Added component #4 compatibility for Skills and Abilities component #131's separate Enhanced Skald Song: a dedicated `IWTFSK7.SPL` selector is built from resources already installed by S&A.
- Replaced the unchanged stock portrait icon for Curran Strongheart's War Chant with IWDEE's native Resist Fear icon.
- Replaced the unchanged stock portrait icon for Tymora's Melody with IWDEE's native Good Luck icon.
- Other classic Bard Songs retain the Bard Song note, and third-party icon replacements are preserved.

v0.3
----
- Integrated Ranger Tracking HLA cleanup into component #0.
- Ranger and Ranger-kit HLA routing is handled dynamically so shared HLA tables are not modified for kits that do not already receive Tracking through their normal CLAB progression.
- Added component #4: Make Enhanced Bard Song Switchable.
- Component #4 builds a seventh Bard Song selector from the installation's current IWDEE resources and removes only SPCL920 immunities that block genuine Change Bard Song switchers.
- Bardic Wonders is not a dependency for component #4 and no packaged resources from it are redistributed.
- Added component #5: Bardic Wonders Extend Revised Bard Song Mechanics to IWDEE Classic Songs.
- Component #5 extends Bardic Wonders' installed Revised Bard Song Mechanics to the six classic IWDEE Bard Songs while preserving the installation's current song payloads.
- Ranger Tracking handling passed dedicated in-game tests.
- Components #4 and #5 are runtime-validated: Enhanced Bard Song and all six classic IWDEE songs apply their real effects, preserve the Bardic Wonders cooldown/switching behavior, and remain active while the Bard attacks or casts.
- Enhanced Bard Song portrait status icons are visible in game.
- Classic-song `C0IWSONG` / `C0SINGI2` compatibility is validated.
- Consolidated the final Bard Song fixes: short-resref `WRITE_ASCIIE` writes use explicit 8-byte fields, and `IWTFBEFX.SPL` is created without the `BUT_ONLY` condition that previously prevented creation of the new payload resource.
- Component #4 uses the IWDEE/EBS-specific Bardic Wonders wrapper shape so cooldown and actual EBS payload effects both apply.
- Component #5 preserves Bardic Wonders IWDEE song-selection state (`C0IWSONG` 1-6), registers all six classic songs in `C0SINGI2` cleanup handling, and preserves the validated 8-byte EFF resref handling.
- Split the component bodies into dedicated `.tpa` files while keeping component-level `REQUIRE_PREDICATE` checks in the main TP2, matching WeiDU's parsing rules.
- Final release-candidate validation completed successfully: all six components installed cleanly with WeiDU 24900, and the consolidated build was then verified in game with no regressions found.

v0.2
----
- Added an IWDEE adaptation of Tweaks Anthology component #2340: Remove Summoning Cap for Celestials.
- The new component raises the CELESTIAL limit in SUMMLIMT.2DA to 999, allowing multiple active Planetars/Devas.
- Confirmed in-game on IWDEE v2.7.3.0 with multiple celestial summons active simultaneously.
- Added compatibility checks to avoid stacking the component with Tweaks Anthology #2340.
- Updated documentation and third-party attribution for the new component.

v0.1
----
- Initial public release.
- Added standalone BG2-style HLA support for IWDEE with Infinity UI++ compatibility.
- Skills and Abilities is optional: components #710/#720 are supported, while #730 should be skipped.
- Added self-contained LUNUMAB fallback handling and local MOHLA01 compatibility-marker generation.
- Added expanded Fighter/Mage/Thief and Fighter/Mage/Cleric HLA tables based on the Tweaks Anthology component behavior.
- Triple-class HLA tables are created dynamically from the installation's current HLA resources when needed; no Tweaks Anthology HLA tables are redistributed.
- Added Infinity UI++-compatible thief skill point assignment in multiples of five, based on the Sword Coast Stratagems tweak.
- Added compatibility checks, install-order warnings, documentation and credits.
