IWDEE Tweaks and Fixes - Changelog
==================================

v0.3a
-----
- Added component #4 compatibility for Skills and Abilities component #131's separate Enhanced Skald Song: a dedicated `IWTFSK7.SPL` selector is built from resources already installed by S&A.
- Replaced the unchanged stock portrait icon for Curran Strongheart's War Chant with IWDEE's native Resist Fear icon.
- Replaced the unchanged stock portrait icon for Tymora's Melody with IWDEE's native Good Luck icon.
- Other classic Bard Songs retain the Bard Song note, and third-party icon replacements are preserved.

v0.3
----
- Integrated Ranger Tracking HLA cleanup into component #0.
- Ranger and Ranger-kit HLA routing is handled dynamically so shared HLA tables are not modified for kits that do not already receive Tracking through their normal CLAB progression.
- Added component #4: Make Enhanced Bard Song Switchable.
- Component #4 builds a seventh Bard Song selector from the installation's current IWDEE resources and removes only SPCL920 immunities that block genuine Change Bard Song switchers.
- Bardic Wonders is not a dependency for component #4 and no packaged resources from it are redistributed.
- Added component #5: Bardic Wonders Extend Revised Bard Song Mechanics to IWDEE Classic Songs.
- Component #5 extends Bardic Wonders' installed Revised Bard Song Mechanics to the six classic IWDEE Bard Songs while preserving the installation's current song payloads.
- Ranger Tracking handling passed dedicated in-game tests.
- Components #4 and #5 are runtime-validated: Enhanced Bard Song and all six classic IWDEE songs apply their real effects, preserve the Bardic Wonders cooldown/switching behavior, and remain active while the Bard attacks or casts.
- Enhanced Bard Song portrait status icons are visible in game.
- Classic-song `C0IWSONG` / `C0SINGI2` compatibility is validated.
- Consolidated the final Bard Song fixes: short-resref `WRITE_ASCIIE` writes use explicit 8-byte fields, and `IWTFBEFX.SPL` is created without the `BUT_ONLY` condition that previously prevented creation of the new payload resource.
- Component #4 uses the IWDEE/EBS-specific Bardic Wonders wrapper shape so cooldown and actual EBS payload effects both apply.
- Component #5 preserves Bardic Wonders IWDEE song-selection state (`C0IWSONG` 1-6), registers all six classic songs in `C0SINGI2` cleanup handling, and preserves the validated 8-byte EFF resref handling.
- Split the component bodies into dedicated `.tpa` files while keeping component-level `REQUIRE_PREDICATE` checks in the main TP2, matching WeiDU's parsing rules.
- Final release-candidate validation completed successfully: all six components installed cleanly with WeiDU 24900, and the consolidated build was then verified in game with no regressions found.

v0.2
----
- Added an IWDEE adaptation of Tweaks Anthology component #2340: Remove Summoning Cap for Celestials.
- The new component raises the CELESTIAL limit in SUMMLIMT.2DA to 999, allowing multiple active Planetars/Devas.
- Confirmed in-game on IWDEE v2.7.3.0 with multiple celestial summons active simultaneously.
- Added compatibility checks to avoid stacking the component with Tweaks Anthology #2340.
- Updated documentation and third-party attribution for the new component.

v0.1
----
- Initial public release.
- Added standalone BG2-style HLA support for IWDEE with Infinity UI++ compatibility.
- Skills and Abilities is optional: components #710/#720 are supported, while #730 should be skipped.
- Added self-contained LUNUMAB fallback handling and local MOHLA01 compatibility-marker generation.
- Added expanded Fighter/Mage/Thief and Fighter/Mage/Cleric HLA tables based on the Tweaks Anthology component behavior.
- Triple-class HLA tables are created dynamically from the installation's current HLA resources when needed; no Tweaks Anthology HLA tables are redistributed.
- Added Infinity UI++-compatible thief skill point assignment in multiples of five, based on the Sword Coast Stratagems tweak.
- Added compatibility checks, install-order warnings, documentation and credits.
